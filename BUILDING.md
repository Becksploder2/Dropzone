# Drop Zone downloadable builds

GitHub Actions builds Windows and macOS packages from the Godot 4 project ZIP.

1. Open [Actions](https://github.com/Becksploder2/Dropzone/actions).
2. Open the newest successful **Build Drop Zone** run.
3. In **Artifacts**, download **DropZone-Windows** (EXE plus PCK) or **DropZone-macOS** (application ZIP).
4. Keep `DropZone.exe` and `DropZone.pck` together in the same folder on Windows.

These packages are prototype builds. A successful CI export verifies packaging, not a full graphical gameplay test.
